# Acme Orders

Monorepo for the Acme orders product: web app, mobile app, data pipelines, and AWS infrastructure.

- `web/` React + Vite storefront and dashboard
- `mobile/` Expo app
- `infra/` Terraform and CDK
- `data/` dbt project, Airflow DAGs, Streamlit in Snowflake app
- `api/` billing and payments API specs
- `docs/` ADRs, architecture model, incident notes
