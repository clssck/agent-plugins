# Discovery & Expansion Path

## Summary
Determine if you're extending existing work or building new, then guide expansion users to a quick recommendation.

## Personas
- Data Engineer

## Details
## **What You Will Accomplish**

- Determine whether you're extending an existing pipeline or building something new
- If extending: identify your project and decide whether to continue with the same technology or evaluate alternatives
- If same technology: receive an immediate recommendation with next steps

## **Steps in This Task**

| Step | Title | Purpose | Conditional |
|------|-------|---------|-------------|
| 1 | Work Context | Bifurcation: extend existing or build new | Always |
| A.1 | Project Identification | Describe what you're expanding | Path A only |
| A.2 | Approach Decision | Same tech or evaluate alternatives | Path A only |
