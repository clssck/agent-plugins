## Common Patterns

**Token expiry:** Refresh tokens typically expire after 60-90 days. If the connector stops working after a period of successful operation, expired tokens are the most likely cause.

**Rate limits:** Rate limits vary by platform and account tier. Persistent 429 errors may require requesting a higher rate limit from the ad platform.

---

## Troubleshooting

For ads connector issues, use the OAuth and rate-limit diagnostic queries in `references/connectors/saas-connectors.md`. If the failure is on Snowflake-side processors rather than the source API, load `references/connectors/connector-shared-generic.md` as well. Common issues:
- **OAuth token expiry:** Guide the customer to re-authenticate the connector in the Openflow UI.
- **Rate limiting:** Transient and self-resolving. If persistent, the customer may need to request a higher rate limit from the ad platform.
- **API version errors:** Guide the customer to check if their connector version is current via the Openflow UI connector gallery.
- **Other errors:** Present the error pattern to the customer and guide them to verify their ad platform credentials and API access. Only escalate if the error indicates a product defect (e.g., malformed API request generated by the connector).
