# T06 — Pure Search

Document retrieval only — no structured data. Best for knowledge bases, policy libraries, HR handbooks, runbooks, or any domain where users ask questions answered entirely from documents.

## Tools

```yaml
tools:
  - tool_spec:
      type: cortex_search
      name: <PrimarySearch>
      description: "<What documents this covers — be specific about scope.>"
  - tool_spec:              # omit if only one document collection
      type: cortex_search
      name: <SecondarySearch>
      description: "<What this second collection covers.>"

tool_resources:
  <PrimarySearch>:
    search_service: <DATABASE>.<SCHEMA>.<SEARCH_SERVICE_1>
    id_column: <ID_COLUMN>
    title_column: <TITLE_COLUMN>
    max_results: 5
  <SecondarySearch>:        # omit if only one collection
    search_service: <DATABASE>.<SCHEMA>.<SEARCH_SERVICE_2>
    id_column: <ID_COLUMN>
    title_column: <TITLE_COLUMN>
    max_results: 5
```

If only one document collection is needed, remove `<SecondarySearch>` from both `tools` and `tool_resources`, and drop the routing lines from `instructions.orchestration`.

## Instructions Starter

```yaml
instructions:
  system: |
    You are <PERSONA — role, organization, expertise level>.
    <Core behavioral rules: tone, language, scope constraints, things to avoid.>
    Always cite the source document when quoting or paraphrasing content.
  response: |
    You answer questions about <DOMAIN_TOPIC> using official documents and knowledge base content.
    When you cannot find a clear answer in the documents, say so — do not invent information.
  orchestration: |
    Use <PrimarySearch> for questions about <PRIMARY_COLLECTION_TOPIC>.
    Use <SecondarySearch> for questions about <SECONDARY_COLLECTION_TOPIC>.
    If a question spans both, search both and synthesize a combined answer.
```
