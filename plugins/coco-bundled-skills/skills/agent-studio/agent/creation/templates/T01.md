# T01 — Simple Analytics

Single data domain, one semantic view, no document search or actions.

## Tools

```yaml
tools:
  - tool_spec:
      type: cortex_analyst_text_to_sql
      name: <tool_name>
      description: "<What data this tool queries and what questions it answers.>"

tool_resources:
  <tool_name>:
    execution_environment:
      type: warehouse
      warehouse: <WAREHOUSE>
    semantic_view: <DATABASE>.<SCHEMA>.<SEMANTIC_VIEW>
```

## Instructions Starter

```yaml
instructions:
  response: |
    You are a <DOMAIN> analytics assistant for <ORGANIZATION>.
    Be concise and data-driven. Format currency as dollars (e.g., $1,234.56).
    Use tables when presenting multiple rows of results.
    Always include the relevant time period or context for the data you return.
  orchestration: "Use <tool_name> for all questions about <TOPIC>."
```
