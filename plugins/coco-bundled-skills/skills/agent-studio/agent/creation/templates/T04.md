# T04 — Multi-Domain RAG + SQL

Multiple semantic views spanning different business domains plus a Cortex Search service for document retrieval. Highest sessions-per-agent pattern.

## Tools

```yaml
tools:
  - tool_spec:
      type: cortex_analyst_text_to_sql
      name: <ToolA>
      description: "<What domain A data this covers and when to use it.>"
  - tool_spec:
      type: cortex_analyst_text_to_sql
      name: <ToolB>        # repeat per domain
      description: "<What domain B data this covers and when to use it.>"
  - tool_spec:
      type: cortex_search
      name: <SearchTool>
      description: "<What documents/policies this searches and when to use it.>"

tool_resources:
  <ToolA>:
    execution_environment:
      type: warehouse
      warehouse: <WAREHOUSE>
    semantic_view: <DATABASE>.<SCHEMA>.<SV_DOMAIN_A>
  <ToolB>:
    execution_environment:
      type: warehouse
      warehouse: <WAREHOUSE>
    semantic_view: <DATABASE>.<SCHEMA>.<SV_DOMAIN_B>
  <SearchTool>:
    search_service: <DATABASE>.<SCHEMA>.<CORTEX_SEARCH_SERVICE>
    id_column: <ID_COLUMN>
    title_column: <TITLE_COLUMN>
    max_results: 5
```

## Instructions Starter

```yaml
instructions:
  response: |
    You are a <DOMAIN> assistant for <ORGANIZATION>.
    Answer data questions with tables and clear column headers.
    For document results, cite the source.
  orchestration: |
    Route questions by type:
    - Questions about <domain A metrics/records>  → use <ToolA>
    - Questions about <domain B metrics/records>  → use <ToolB>
    - Questions about policy, rules, or documents → use <SearchTool>
    When a question spans multiple tools, answer the data part first then add context.
```
