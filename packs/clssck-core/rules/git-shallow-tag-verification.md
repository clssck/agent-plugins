**A successful shallow tag command does not prove that `HEAD` is the tagged commit.**

- Resolve the exact remote tag with `git ls-remote --tags <remote> <tag> '<tag>^{}'`: the peeled `^{}` SHA for an annotated tag, the direct SHA for a lightweight tag.
- Fetch that exact tag ref and check it out detached; do not rely only on `clone --depth … --branch <tag>`.
- Verify `git rev-parse HEAD` equals `git rev-parse '<tag>^{}'` (or the SHA observed from `ls-remote`), then report that SHA.
- NEVER claim a checkout is pinned to a tag from command success, branch text, or `git describe` alone.
