**Command output lands in the session transcript, logs, and model context. A printed secret is a leaked secret.**

- Check presence without the value: `[ -n "$API_KEY" ] && echo set`, or `printenv | cut -d= -f1 | grep -i api` to list names only.
- Use secrets in place, never echo them: `curl -H "Authorization: Bearer $TOKEN" ...`, `TOKEN=$(gh auth token) cmd`.
- Need to compare two secrets? Compare fingerprints: `printf %s "$TOKEN" | shasum -a 256 | cut -c1-12`.
- NEVER `cat` a `.env` file, `printenv` a secret, or pipe `env`/`printenv` into `grep`; read the variable names, or `grep -c` / `cut -d= -f1`.
- A secret already printed? Say so in the report so the user can rotate it.
