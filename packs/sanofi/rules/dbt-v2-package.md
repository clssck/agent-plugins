**The bare `dbt` package on PyPI is dbt v2 (the Rust Fusion engine), not dbt Core 1.x.**

- Since 2026-09-14, `dbt` 2.x is published under that name, so `pip install dbt`, `uv add dbt`, `uvx dbt`, and `uv run --with dbt` all resolve to v2.
- For a v1 project, NEVER install bare `dbt`. Install `dbt-core` plus the adapter at the repository's pins (`dbt-core==<pin>`, `dbt-snowflake==<pin>`), or use the project's locked environment.
- One-off v1 CLI: `uvx --from 'dbt-core==<pin>' --with 'dbt-snowflake==<pin>' dbt <command>`.
- Install v2 only when the user or repository adopted it. State that it is deliberate and pin an exact version (`dbt==<version>`); this reminder still appears on that command.
- Run `dbt --version` before trusting parse, build, or test output; it names the engine on `PATH`.
- `dbt-core`, `dbt-<adapter>`, `dbt-autofix`, `dbt==1.*`, and `dbt<2` are not flagged.
