# Default Plain Text Template

Generate ASCII table format for any destination.

## Input

**Required (one of):**
- **Query ID** — a query_id from `RESULT_SCAN` or `SNOWFLAKE.ALERT.GET_CONDITION_QUERY_UUID()`
- **Message body** — a plain text string

**Optional:**
- **Header text** — title displayed above the table
- **Footer text** — closing message below the table
- **Column metadata** — ordered list of column names/aliases from the source query (e.g., `['EVENT_TIME', 'DT_NAME', 'STATE']`). When provided, use these directly instead of `DESCRIBE RESULT`.

## Generation Steps

1. **If query_id provided:**
   - **If column metadata provided:** Use the column names directly for header row and data row access — skip `DESCRIBE RESULT` entirely.
   - **If column metadata NOT provided:** Discover columns via `DESCRIBE RESULT '<query_id>'`
   - Fetch data: `SELECT * FROM TABLE(RESULT_SCAN('<query_id>')) LIMIT 100`
   - Build header row, separator, and data rows from column names and values
2. **If message body provided:**
   - Use the message text directly (no ASCII table)
3. **Build the SQL content block** using the plain text template below

**⚠️ DESCRIBE RESULT fallback (only when column metadata NOT provided):**

`DESCRIBE RESULT` is a **standalone statement** — run it first, then read output via `RESULT_SCAN(LAST_QUERY_ID())`. Do NOT embed it in a SELECT or cursor — that is a syntax error.

| Access pattern | Resolves to | Result |
|---|---|---|
| `"name"` in SELECT | `"name"` (lowercase) | ✅ Correct |
| `name` in SELECT | `NAME` (uppercased) | ❌ Error: column does not exist |
| `col_rec."name"` in cursor | cursor field `"name"` | ✅ Correct |
| `col_rec.name` in cursor | cursor field `NAME` | ❌ Error: column does not exist |

## Template Structure

```
{HEADER_TEXT}
================================================================================

| Column1        | Column2        | Column3        |
|----------------|----------------|----------------|
| value1         | value2         | value3         |
| value4         | value5         | value6         |

{ROW_COUNT} row(s) returned

--------------------------------------------------------------------------------
{FOOTER_TEXT}
```

## Building the String in SQL

**CRITICAL:** Use `\\\\n` for all newlines when building for webhooks.

```sql
LET message VARCHAR := 
  :header_text || '\\\\n' ||
  '================================================================================' || '\\\\n' ||
  '\\\\n' ||
  :table_content || '\\\\n' ||
  '\\\\n' ||
  :row_count || ' row(s) returned' || '\\\\n' ||
  '\\\\n' ||
  '--------------------------------------------------------------------------------' || '\\\\n' ||
  :footer_text;
```

## Building Table Rows

### Option A: Column metadata provided (preferred)

When column metadata is passed (e.g., `['REGION', 'SALES', 'GROWTH']`), use the column names directly for the header and data rows. No `DESCRIBE RESULT` needed.

```sql
LET header_text VARCHAR := 'Daily Sales Report';
LET footer_text VARCHAR := 'Generated by Snowflake Alert System';

-- Build header and separator from known column names
LET table_header VARCHAR := '| REGION         | SALES          | GROWTH         |';
LET table_sep VARCHAR :=    '|----------------|----------------|----------------|';

-- Build data rows using the same column names
LET table_data VARCHAR := '';
LET row_count INT := 0;
LET c CURSOR FOR (SELECT * FROM TABLE(RESULT_SCAN('<query_id>')) LIMIT 100);
FOR rec IN c DO
  table_data := :table_data || '| ' || RPAD(COALESCE(rec.REGION::VARCHAR, ''), 14) 
    || ' | ' || RPAD(COALESCE(rec.SALES::VARCHAR, ''), 14)
    || ' | ' || RPAD(COALESCE(rec.GROWTH::VARCHAR, ''), 14) || ' |\\\\n';
  row_count := :row_count + 1;
END FOR;
```

Replace the example column names (`REGION`, `SALES`, `GROWTH`) with the actual column names from the column metadata.

### Option B: No column metadata — use DESCRIBE RESULT (fallback)

`DESCRIBE RESULT` is a **standalone statement**. Run it first, then access output via `RESULT_SCAN(LAST_QUERY_ID())`:

```sql
-- Step 1: Run DESCRIBE RESULT as a standalone statement
DESCRIBE RESULT '<query_id>';

-- Step 2: Build table content from actual columns and data
LET table_content VARCHAR := (
  SELECT 
    -- header: one '| Column |' per actual column name from DESCRIBE RESULT
    -- separator: one '|--------|' per column
    -- rows: one '| value |' per column using actual column names
    LISTAGG(
      -- build each row dynamically from all columns
      '\\\\n'
    )
  FROM TABLE(RESULT_SCAN('<query_id>'))
);
```

**⚠️** `DESCRIBE RESULT` returns **lowercase** column names — double-quote them: `"name"` not `name`.

## Formatting Rules

- Auto-size columns based on content (max 30 chars per column)
- Truncate long values with "..."
- Use `RPAD()` to align columns
- Header separator: `=` (80 chars)
- Footer separator: `-` (80 chars)

## Content Wrapping

Wrap the final plain text message with `SNOWFLAKE.NOTIFICATION.TEXT_PLAIN()`:

```sql
SNOWFLAKE.NOTIFICATION.TEXT_PLAIN('<message>')
```
